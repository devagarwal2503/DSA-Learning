## 🎯 What Is This Repo?

> *"An algorithm must be seen to be believed."* — **Donald Knuth**

This is my **personal, structured DSA operating system** — built to follow [Striver's A2Z DSA Course](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2) from zero to interview-ready, in public.

I transitioned from a pattern-based playlist to the **gold standard** of DSA prep. Every file here reflects real-time learning — raw problem-solving, annotated C++ solutions with complexity proofs, "Aha!" intuition notes, and a fully scaffolded 471-problem tracker across 20 steps.

> **Fork this repo → Replace my name → Track your own A2Z journey.** 🚀

### What Makes This Different?
| Feature | Description |
|---|---|
| 📁 **Full 20-Step Scaffold** | Every subfolder, tracker, and notes file pre-built — nothing to set up |
| 📊 **Problem Dashboards** | Rich `problems.md` with 🟢 Basic / 🔵 Core / 🔴 Pro difficulty tags, platform links, solution links, and status |
| 📖 **Concept Notes** | Per-step `notes.md` templates capturing theorems, common mistakes, and reusable code patterns |
| 💻 **C++ Template** | [`TEMPLATE.cpp`](./TEMPLATE.cpp) with AHA! moment annotation, complexity docs, edge case analysis |
| 📦 **Preserved History** | 14 solved GFG problems + earlier notes safely archived in [`archive/`](./archive) |

## ⚔️ Dev's Ironclad Code of Conduct

```
🕐 30-MINUTE RULE     → Never watch solution before a genuine 30-min attempt
📝 DRY-RUN FIRST      → Trace with pen & paper on ≥2 edge cases before coding
📈 BRUTE → OPTIMAL    → Always establish baseline before optimizing
💡 "AHA!" RULE        → Every solution file must annotate the core unlocking insight
📐 COMPLEXITY PROOF   → Document Time O(?) and Space O(?) with tight justification
```

These aren't guidelines — they're **non-negotiable**. Every `.cpp` file must satisfy all five before it's marked ✅.

## 🛠️ Workflow: How to Solve a Problem

```bash
# Step 1 — Pick a problem from the target step's problems.md tracker
# Step 2 — Copy the template
cp TEMPLATE.cpp Step_01_Basics/1.4_Basic_Maths/solutions/count_digits.cpp

# Step 3 — Code, test, and compile
g++ -std=c++20 -O2 -Wall Step_01_Basics/1.4_Basic_Maths/solutions/count_digits.cpp -o sol
./sol

# Step 4 — Update status in problems.md: 🔒 → ✅
# Step 5 — Capture your insight in the step's notes.md
```
